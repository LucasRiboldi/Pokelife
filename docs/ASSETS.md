# Créditos e origem dos recursos

| Recurso | Origem |
| --- | --- |
| Sprites dos três iniciais | Sprites da [PokéAPI](https://github.com/PokeAPI/sprites). O [aviso de origem](https://github.com/PokeAPI/sprites/blob/master/LICENCE.txt) atribui as imagens à The Pokémon Company. |
| Animação provisória do Charmander | Atlas criado no projeto com o [gerador de Viridian](../referencia/gerar-viridian.py). O personagem pertence aos respectivos titulares. |
| Floresta de Viridian | O [mapa-base fornecido ao projeto](../referencia/MAPA%20FINAL%201.png) e as peças geradas pelos [scripts do habitat](../referencia/Plano-Navegacao-Habitat.md) compõem a cena. A prévia do README mostra esse mapa. |
| Referência de comportamento | Análise das animações e do habitat apresentados por Ronald Brenner Dev. [Perfil do autor](https://www.instagram.com/ronaldbrennerdev/) |

O projeto tem caráter de protótipo de aprendizado. O código próprio ainda não tem licença de código aberto. Os materiais de terceiros seguem os direitos de seus titulares. A troca dos sprites por arte original é uma etapa prevista antes da distribuição de uma versão jogável.
